# Interview AI

A frontend interview practice web application designed to help students prepare for technical interviews through role-based mock interview practice.

## 🌐 Live Demo

**[Open Interview AI](https://niranjana-2007.github.io/AI-Interview-Assistant/)**

## 📌 About the Project

Interview AI is a beginner-friendly frontend project that simulates an interview practice experience.

Users can select a developer role, answer a set of role-specific interview questions, receive instant rule-based feedback, track their progress, and review their final performance.

The project was designed and developed using HTML, CSS, and JavaScript.

## ✨ Features

* Role-based interview practice
* Software Developer, Frontend Developer, Backend Developer, and Python Developer roles
* Role-specific interview questions
* Progress tracking during the interview
* Instant answer feedback
* Automatic practice score
* Final result and performance summary
* Answer review after completing the interview
* Responsive design for different screen sizes
* Clean and minimal user interface
* Local storage for maintaining interview data

## 🛠️ Tech Stack

* **HTML5** – Page structure and semantic elements
* **CSS3** – Styling, layout, responsiveness, and visual design
* **JavaScript** – Interview logic, scoring, navigation, and user interaction
* **LocalStorage** – Temporary storage of interview progress and results
* **GitHub Pages** – Website deployment

## 🔄 How It Works

1. Open the Interview AI website.
2. Choose a developer role.
3. Start the mock interview.
4. Answer the interview questions.
5. Receive instant feedback.
6. Complete all questions.
7. View your final score and performance.
8. Review your answers.
